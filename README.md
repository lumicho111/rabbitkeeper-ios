# RabbitKeeper iOS

RabbitKeeper 的 iOS 安装包与版本更新发布仓库。

> 当前状态：筹备中。尚未发布经过验证的 IPA，也尚未开放可用的 AltStore Classic 软件源。

## 分发计划

- **Releases**：发布经过构建、检查的 IPA 文件与版本说明。
- **AltStore Classic**：首个有效 IPA 发布后启用 `source.json`，用户使用自己的签名方式安装和续签。
- **源码**：主工程在独立仓库维护；本仓库不公开完整业务源码、密钥或证书。
- **更新**：正式版由主工程触发构建，验证构建产物后发布到此仓库，并更新 AltStore 版本索引。

## 安装说明

目前尚无 IPA 可安装。正式发布后将提供下载链接、软件源地址、兼容系统和自签注意事项。AltStore Classic 免费 Apple 账户签名一般需要定期续签；软件源仅提供更新信息，不能替代签名。
